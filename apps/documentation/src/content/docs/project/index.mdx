## What we are building

A management app for a **participative grocery run at a single location**, inspired by
[MonÉpi](https://www.monepi.fr) (wiki: [wiki.monepi.fr](https://wiki.monepi.fr/doku.php)).

MonÉpi is a shared platform for many grocery cooperatives. We only need one cooperative,
one place. That removes the heaviest parts: multi-tenant hosting, the directory of
cooperatives, and group orders between cooperatives.

## Status

Lots 1 to 4 are implemented — the full cycle: order, buy, receive, distribute, pay.

- [Lot 1 — Foundation](/grocery/project/lot-1-foundation): members, roles, catalogue.
- Lot 2 — Shop and orders: the public shop, the cart, pre-order versus in-store order
  (`specs/shop-orders/`).
- [Lot 3 — Purchasing](/grocery/project/lot-3-purchasing): aggregation, reception, stock and
  cost price.
- [Lot 4 — Distribution](/grocery/project/lot-4-distribution): the table screen, express
  orders, and the member account ledger.
