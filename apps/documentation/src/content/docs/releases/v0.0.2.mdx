---
title: v0.0.2
description: Member lifecycle, catalogue, and the first version of the public shop
---

This release brings the co-op's core workflows online: members can join and manage their account, admins can run the catalogue, and the public shop takes its first real orders.

- **Members**: sign-up (email or phone), admin validation, roles, membership fees, and termination/reactivation.
- **Catalogue**: suppliers, categories, and products with a full price history.
- **Shop**: browse, add to cart, and check out — orders are split by ordering mode (pre-order, in-store, or both).
- Also in this release: an end-to-end test suite for the web app, and the project's rebrand from the Lonestone boilerplate to Grocery.

No public release existed before this one, so `v0.0.2` is effectively where the project's history starts.
