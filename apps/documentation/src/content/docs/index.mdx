Grocery is a fullstack, fully-typed TypeScript monorepo — a NestJS API and a React SPA.

Featuring:

- Full-stack typing
- Docker-based development environment
- OpenAPI-based API
- React frontend app
- NestJS backend API
- MikroORM for database
- Better Auth for authentication
- Shadcn UI for components
- Tailwind CSS for styling

Built on the [Lonestone boilerplate](https://github.com/lonestone/lonestone-boilerplate).
